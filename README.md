# Personal portfolio

A modern personal portfolio website built with Next.js, designed to showcase projects, skills, and experience. The application leverages server-side rendering (SSR) and static site generation (SSG) for optimal performance and SEO. Styled with <img width="20" height="15" src="https://mui.com/static/logo.svg" alt="Material UI logo"> Material UI and deployed to <img src="https://assets.vercel.com/image/upload/v1588805858/repositories/vercel/logo.png" height="17"> Vercel.
